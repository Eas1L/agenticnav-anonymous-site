# AgenticNav

Zero-Shot Vision-and-Language Navigation as a Tool-Calling Harness.

Anonymous research website for peer review. The static website is in `docs/`.

The page includes five current real-world experiments, an interactive instruction
player, the paper architecture figure, and interactive action, depth, and recall tools.
The five experiments retain the full recorded task at a constant ten times speed.
The background contains 25 seconds of selected navigation highlights.

All page resources use relative paths. Videos load when selected for playback.
The page includes a fallback for hosts without media byte-range support, so clicking
an instruction can still seek after the selected video has loaded.

Author identities, institutional details, signed publication links, and personal
contact information are omitted. The previously approved identity-masked footage
is reused for the kitchen, sign-following experiment, and recalled observation.
